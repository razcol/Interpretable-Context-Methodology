# Outlook Email Manager

Triage unread Outlook Classic email and draft replies in your own voice.

## Task Routing

| Task Type | Go To | Description |
|-----------|-------|-------------|
| Triage unread email | `stages/01-triage/CONTEXT.md` | Categorize, label, and prioritize unread email |
| Draft replies | `stages/02-draft-replies/CONTEXT.md` | Draft replies for every email flagged needs-reply |
| Learn or refresh voice | `tone-profile/CONTEXT.md` | One-time setup: derive a voice profile from sent email |
| Find a specific email or value | `shared/email-lookup-guide.md` | Ad-hoc read-only lookup: search the user's literal term first, then open the top hits |

## Shared Resources

| Resource | Location | Contains |
|----------|----------|----------|
| Priority rubric | `shared/priority-rubric.md` | Scoring signals, weights, VIP sender list |
| Category map | `shared/category-map.md` | Previously approved Outlook category matches |
| Tone profile | `shared/tone-profile.md` | Voice reference derived from sent email, plus manual notes |
| Email lookup guide | `shared/email-lookup-guide.md` | How to query the mailbox for a specific value or email |
| Outlook automation skill | `skills/outlook-automation/SKILL.md` | outlookctl CLI commands for reading, categorizing, and drafting in Classic Outlook |
